# 🥚 BUGZ Egg Catch

A fan mini-game for the **UnVault** NFT marketplace starring a **Genesis Bugz**.
Move the Bugz left and right, catch the falling eggs in the UnVault nest, and dodge rocks, red candles and spikes.

## How to play
- **Move:** ← → or A / D, or drag on the screen (mobile)
- **Egg:** +10 · **Golden egg:** +50 and a 6-second shield
- **Rock / red candle / spike:** −15 / −20 / −25 (blocked while the shield is on)
- **Magnet:** pulls nearby eggs in for 5 seconds
- **20 combo:** BUGZ FRENZY, 5 seconds of x3 egg rain
- **10 eggs in the nest:** vault deposit, +100
- 60 seconds per round. Share your score on X at the end.

## Run
It's a single `index.html` with every asset embedded, so there is no build step.
Open it in a browser, or deploy the repo to Vercel as a static site.
